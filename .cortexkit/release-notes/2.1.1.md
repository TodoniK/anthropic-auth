## What's fixed

- **One copy of the vault client.** The OpenCode package in 2.1.0 depended on an older `@cortexkit/claustrum-client` (0.11.0) than Core (0.12.0), so every install had two copies: the setup command used one and the plugin's Core the other. An error raised by one copy isn't recognized by checks written against the other, so setup could report a vault error as an unexpected one. OpenCode now depends on the same version as Core. The plugin's requests were not affected.
- **Checks that keep it that way.** A test requires OpenCode's copy of each Core runtime package to use exactly Core's version, and the packed-install check now installs the published OpenCode and Pi packages fresh and fails if either shared client (`claustrum-client` or `subc-client`) is installed twice.

To upgrade, quit OpenCode and run `npx @cortexkit/opencode-anthropic-auth@2.1.1 setup`, or change the version in your OpenCode config.
